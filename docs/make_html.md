# User-Guide

## Mkdocs quick start

### Installation
> **Requires Python 3.10+.** On older Python `pip install` fails with `No matching distribution found`.  
To install MkDocs, run the following command from the command line:

```
pip install "mkdocs==1.6.1"
pip install "mkdocs-material==9.6.14"
pip install "pymdown-extensions==10.15"
pip install "mkdocs-to-pdf==0.11.2"
pip install "weasyprint==62.3"
pip install "pydyf==0.10.0"
```
* https://github.com/orzih/mkdocs-with-pdf 

### Building the site
```
mkdocs build
```

### Start the server 
```
mkdocs serve
```
